## 📌 Giới thiệu
Đây là dự án **Web Bán Hoa** của nhóm 10. Mục tiêu của dự án là xây dựng một website thương mại điện tử chuyên về hoa, giúp người dùng dễ dàng tìm kiếm, đặt mua và thanh toán trực tuyến.

---

## 🚀 Tính năng chính
- Trang chủ giới thiệu các loại hoa nổi bật.  
- Danh mục sản phẩm theo chủ đề (hoa sinh nhật, hoa cưới, hoa chúc mừng...).  
- Giỏ hàng và thanh toán trực tuyến.  
- Trang quản trị để thêm/sửa/xóa sản phẩm.  
- Tìm kiếm sản phẩm nhanh chóng.  

---

## 🛠️ Công nghệ sử dụng
- **Front-end:** HTML, CSS, JavaScript  
- **Back-end:** PHP / Node.js (tùy chọn)  
- **Cơ sở dữ liệu:** MySQL
